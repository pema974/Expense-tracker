# Expense Tracker

A web-based Expense Tracker built with PHP to help users manage their personal finances by tracking income and expenses.

## Features

- User registration and login
- Track income and expenses
- Manage transactions and categories
- Set and manage budgets
- View financial reports
- Export financial data

## Technologies Used

- PHP
- CSS
- Composer

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/pema974/expense-tracker.git
   ```

2. Enter the project directory:

   ```bash
   cd expense-tracker
   ```

3. Install dependencies if required:

   ```bash
   composer install
   ```

4. Configure your local database connection in `db.php`. Do not publish your database credentials.

5. Create and configure the database required by the application.

6. Start your local PHP development server:

   ```bash
   php -S localhost:8000
   ```

7. Open `http://localhost:8000` in your browser and navigate to the application's login or registration page.

## Security

- Keep database credentials private.
- Do not commit passwords, API keys, or other secrets.
- Use a local development database when testing.
